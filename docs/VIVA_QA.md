# Comprehensive Viva Q&A Guide (30 Technical Questions & Answers)

---

### Q1: Why did you select the OSCD (Onera Satellite Change Detection) dataset?
**A:** OSCD is a recognized multispectral change-detection benchmark consisting of 100 aligned Sentinel-2 satellite image pairs across diverse global geographic locations. It provides multi-band imagery (10m–20m GSD) and human-annotated binary change masks.

### Q2: What is binary change detection vs semantic change detection?
**A:** Binary change detection identifies *where* a surface change occurred ($0 = \text{no change}, 1 = \text{change}$). Semantic change detection goes further by determining *what class* overlaps the changed area ($T_1 \rightarrow T_2$ land-cover class transitions).

### Q3: Why did you choose XGBoost over a Deep Learning CNN/U-Net?
**A:** 
1. **Hardware Constraint:** The project required 100% CPU compatibility without GPU hardware.
2. **Tabular Feature Efficiency:** XGBoost trains quickly on tabular spectral/spatial pixel vectors ($< 0.40$s per scene).
3. **Interpretability:** Feature importance scores highlight which spectral channels contribute most to change prediction.

### Q4: Why is CPU compatibility important for this system prototype?
**A:** CPU compatibility ensures low-cost deployment on standard cloud edge servers or lightweight field laptops without requiring expensive GPU compute instances.

### Q5: What satellite bands were extracted from Sentinel-2?
**A:** B02 (Blue, 490nm), B03 (Green, 560nm), B04 (Red, 665nm), B08 (NIR, 842nm), and B11 (SWIR, 1610nm).

### Q6: What are $T_1$ and $T_2$?
**A:** $T_1$ represents the earlier satellite acquisition date, and $T_2$ represents the later acquisition date over the identical geographic extent.

### Q7: What formula is used for NDVI (Normalized Difference Vegetation Index)?
**A:** $$\text{NDVI} = \frac{\text{NIR} - \text{Red}}{\text{NIR} + \text{Red} + \epsilon}$$

### Q8: What formula is used for NDBI (Normalized Difference Built-up Index)?
**A:** $$\text{NDBI} = \frac{\text{SWIR} - \text{NIR}}{\text{SWIR} + \text{NIR} + \epsilon}$$

### Q9: How many features are fed into the XGBoost classifier?
**A:** 32 tabular features: spectral band differences, band ratios, 3x3 local mean/std texture statistics, Sobel edge magnitude, and distance transform features.

### Q10: How did you handle class imbalance in the training data?
**A:** Changed pixels account for $< 5\%$ of total pixels in satellite imagery. We used XGBoost's `scale_pos_weight` parameter ($N_{\text{neg}} / N_{\text{pos}}$) to balance positive change gradients.

### Q11: What probability threshold was selected for final inference, and why?
**A:** Probability threshold $0.72$ was selected based on validation set F1 optimization. Higher thresholds ($0.72$) suppress illumination and seasonal noise while maintaining high precision.

### Q12: What post-processing operations are performed on the raw prediction map?
**A:** Morphological $3 \times 3$ closing to fill small internal pinholes, followed by Connected Component Analysis (CCA) to remove isolated noise regions $< 3$ pixels.

### Q13: What is the IoU (Intersection over Union) metric?
**A:** $$\text{IoU} = \frac{TP}{TP + FP + FN}$$
IoU measures spatial overlap between predicted change masks and ground truth annotations.

### Q14: Why is overall accuracy alone a misleading metric for change detection?
**A:** Because unchanged pixels comprise $> 95\%$ of satellite scenes. A dummy classifier predicting "No Change" everywhere would achieve $> 95\%$ accuracy while having $0.0$ F1 and $0.0$ IoU.

### Q15: How are road-overlapping changes identified?
**A:** Built-up pixels (high NDBI, low NDVI) undergo morphological thinning; linear features with local width $\le 5$ pixels are categorized as road class.

### Q16: Does the OSCD dataset contain ground truth road labels?
**A:** No. OSCD provides binary change masks only. Semantic classes are derived via rule-based spectral indices (NDVI/NDWI/NDBI) and morphological distance transforms.

### Q17: What are the qualitative change types generated by the system?
**A:** `New` (0 $\rightarrow$ Class), `Removed` (Class $\rightarrow$ 0), `Expanded` (Class $\rightarrow$ Class), `Transition` (Class A $\rightarrow$ Class B), and `Unknown`.

### Q18: How is the Significance Score calculated for a region?
**A:** $$\text{Significance Score} = \left( \frac{\text{Area (pixels)}}{100} \right) \times P_{\text{mean}}$$

### Q19: What causes the majority of False Positives?
**A:** Seasonal agricultural vegetation shifts ($38.2\%$) and solar illumination/shadow variations ($25.5\%$).

### Q20: What causes False Negatives?
**A:** Resolution limits truncating small objects $< 10\text{m}$ ($41.2\%$) and low spectral contrast built-up materials ($25.9\%$).

### Q21: How was data leakage prevented between training and testing?
**A:** The dataset was split by geographical scene boundaries (60 train scenes, 20 validation scenes, 20 test scenes). Test scenes were held out and evaluated only once on Day 9.

### Q22: What is the mean F1-score of the final XGBoost model?
**A:** $0.4606 \pm 0.2125$ (Median: $0.4591$), representing a $+110.9\%$ improvement over the simple difference baseline ($0.2184$).

### Q23: Why can't the system claim "Confirmed Road Construction"?
**A:** Satellite spectral shifts indicate land-cover changes, but cannot confirm human intent or real-world physical activities without ground-truth verification.

### Q24: What is the role of the distance transform feature?
**A:** It computes Euclidean distance to nearest built-up pixel clusters, providing spatial contextual features for surrounding bare land vs infrastructure.

### Q25: How does the Flask web app handle large file uploads?
**A:** Uploaded images are checked against a 32MB size ceiling, validated for format extensions, resized to match dimensions if needed, and assigned isolated `run_id` directories.

### Q26: What API endpoint is exposed for programmatic access?
**A:** `POST /api/detect`, which accepts image file pairs or scene IDs and returns structured JSON containing bounding boxes, change metrics, and transition matrices.

### Q27: How does the system handle Unknown semantic classes?
**A:** Pixels failing spectral confidence thresholds are assigned Class 6 (`Unknown`), preventing forced incorrect classification.

### Q28: How does spatial resolution impact performance?
**A:** Sentinel-2's 10m GSD cannot resolve objects $< 10\text{m} \times 10\text{m}$ (e.g., individual narrow power lines or small vehicles).

### Q29: What happens if $T_1$ and $T_2$ images have slight spatial misalignment?
**A:** A quality flag `alignment_ok: false` is raised, and sub-pixel registration edge noise is logged.

### Q30: What would you improve in future work given GPU hardware?
**A:** Implement a multi-temporal Siamese U-Net or Transformer network trained on fine-grained semantic segmentation datasets (e.g., SpaceNet or LandCoverAI).
